## Workout Types

Extend beyond gym workouts:

| Type | Tracking Method |
|------|-----------------|
| Gym | weight × reps per set (current) |
| Yoga | duration per session |
| Pilates | duration per session |
| Swimming | laps/distance with sets |
| Running | distance + duration |
| Cycling | distance + duration |
| Other activities | configurable |

**Session Creation Flow:**
- Select workout type
- Date picker (defaults to today)
- Type determines tracking UI
